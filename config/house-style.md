# ハウススタイル規約（生成物の固定ルール）

生成するアプリは必ず以下の規約に従うこと。これはシステムプロンプトの固定部分であり、毎回同じ内容が使われる。

## 絶対条件

- 単一 HTML ファイル。CSS・JavaScript はすべてファイル内にインラインで含める。
- 外部ネットワークアクセス禁止: `fetch` / `XMLHttpRequest` / `WebSocket` / CDN / 外部フォント / 外部画像はすべて不可。画像を使う場合は SVG や Canvas を自前で描画するか、`data:` URI のみ許可。
- 依存パッケージ・ビルド工程なし。そのままブラウザで開いて動くこと。
- 状態は `localStorage` のみ。サーバー送信・cookie は不可。
- 全体を `try/catch` で保護し、入力が空でもエラーにならず動くこと。
- ファイルサイズは 200KB 以下。目安は 15〜40KB。

## 表示・操作

- ダークモード対応: `prefers-color-scheme` を必ず扱う。
- モバイル幅（375px）で崩れない。`<meta name="viewport">` を必ず含める。
- キーボード操作ができること（Tab で操作可能・Enter/Space で発火）。
- `prefers-reduced-motion` を尊重し、アニメーションを抑制する。
- テキストは読みやすく、日本語表示が崩れないこと。

## 内容

- 実在のブランド名・実在の人物名・既存サービスの模倣を含めない。
- 医療・法律・投資の助言をする機能は含めない。
- フッターに「生成日: YYYY-MM-DD」「お題の出所: ユーザー投稿 / 自動」を必ず記載する。
- タイトル・タグライン・説明は簡潔で、1 つの軸に絞る。

## 出力ルール

- 出力は完成した HTML ファイルのコードのみ。Markdown のコードフェンス（```html）や説明文は付けない。
- HTML は `<!doctype html>` で始め、閉じタグを漏らさない。
